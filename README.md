Billetera Virtual 💳
A virtual wallet system developed in C as a university project.
Features

Deposit money
Transfer money between accounts
Check balance
View transaction history
View contacts

Technologies

Language: C
File handling for data persistence

How to run

Clone the repository
Compile with GCC: gcc main.c -o billetera
Run: ./billetera
